# Aurora Hack

Landing page for Aurora Hack — an AI hackathon in London, November 2026.

## Preview locally

```bash
python3 -m http.server 8080
```

Then open [http://127.0.0.1:8080/](http://127.0.0.1:8080/) — use the root URL, not `/dashboard/`.

**Arc browser:** If you see a 404, check the address bar. Arc often autocompletes to `localhost:8080/dashboard/` from a previous project. Paste `http://127.0.0.1:8080/` in a fresh tab instead.
